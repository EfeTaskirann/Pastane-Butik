INTERNAL PHP HELPER CLASSES
--------------------------------------------------------------------------------

The following helper classes under `includes/` are original work by the Tatlı
Düşler author and fall under the main license (see LICENSE.txt):

  JWT.php                 — Minimal JWT encoder/decoder
  RateLimiter.php         — In-memory + DB-backed rate limiter
  SecurityAudit.php       — Security event recorder
  TwoFactorAuth.php       — TOTP implementation (RFC 6238)
  PasswordPolicy.php      — Password policy validator
  Logger.php              — PSR-3 compatible logger
  Cache.php               — File + Redis cache driver
  Migration.php           — Schema migration runner
  HealthCheck.php         — Liveness/readiness probes
  EmailService.php        — SMTP + PHPMailer adapter
  SmsService.php          — SMS driver abstraction
  Metrics.php             — Prometheus exposition format
  Sentry.php              — Envelope-based Sentry client

These files are released under the same terms as the main product.
