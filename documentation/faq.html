Installation and server

Q1. I get a "500 Internal Server Error" on the first page load. Where do I look?

The web server log file is your first stop. On Apache it is typically /var/log/apache2/error.log; on cPanel it is under Metrics → Errors. Nine out of ten times the cause is one of:

  • A missing PHP extension (pdo_mysql or mbstring). Run php -m and cross-check against the Installation requirements table.
  • An unreadable .env file - usually wrong ownership after SFTP upload. Run chown -R www-data:www-data . in the document root.
  • APP_DEBUG=true in production revealing a downstream exception. Turn debug off, then read the stack trace from storage/logs/app.log.
Q2. "Permission denied" or "failed to open stream" errors when I upload images or send mail.

The web server user (www-data on Debian-family, apache on RHEL-family, nobody on some shared hosts) does not have write access to storage/ or uploads/. Do NOT use chmod 777. The correct fix is:

sudo chown -R www-data:www-data storage uploads
sudo chmod -R 775 storage uploads
sudo find storage -type f -exec chmod 664 {} \;

If you are on shared hosting, contact your host for the correct user and replace www-data accordingly.

Q3. The installation finished but visiting /admin returns "404 Not Found".

Apache's mod_rewrite module is not loaded, or AllowOverride is restricted in the vhost. Enable with:

sudo a2enmod rewrite
sudo a2enmod headers
sudo systemctl reload apache2

Then make sure the vhost contains <Directory /var/www/pastane>AllowOverride All</Directory>. Reload and retry. Nginx users should review the supplied nginx.conf.example and ensure try_files $uri $uri/ /index.php?$query_string; is in place.

Authentication

Q4. How do I log in for the first time? I do not have credentials anywhere.

The seed script (php bin/db-seed.php) creates a user with username admin and a random password. The password is both printed to the terminal and appended to storage/logs/db-seed.log. If you missed it, re-run:

tail -n 20 storage/logs/db-seed.log

If the log is gone, reset the password with the SQL snippet below. Replace the hash by generating it with php -r "echo password_hash('your-new-password', PASSWORD_BCRYPT, ['cost' => 12]);" first.

UPDATE admin_kullanicilar
SET sifre = '$2y$12$PASTE_THE_GENERATED_HASH_HERE',
    aktif = 1
WHERE kullanici_adi = 'admin';
Q5. How do I reset a lost administrator password?

Two routes are supported. Preferred: another admin user opens Settings → Users, selects the account and clicks "Reset password". An email is sent to the account's address with a time-limited reset link.

Emergency: run the SQL shown in Q4 directly. Immediately after, log in and change the password again through the UI so that it is hashed with the current cost factor and the security event is properly logged.

Never edit the sifre column to plain text. The application uses password_verify(); a plain-text value will silently fail to match.
Q6. "Invalid CSRF token" or "Token expired" errors when submitting a form.

Every form in the admin panel includes a CSRF token scoped to the user's session. Common causes of the error:

  • The session expired while the form was open. Default lifetime is two hours. Reload the page and resubmit.
  • The browser is blocking cookies (private mode with strict tracking prevention). Use a standard window.
  • The site is being served from two domains simultaneously (for example www.example.com and example.com) and the cookie was set on the other. Pick one canonical domain and redirect the other.
  • Load balancer sessions are not sticky. Enable session affinity on your LB or move sessions to Redis.

Role-based access

Q7. Is there role-based access control? How do I make a read-only accountant account?

Yes. Three roles are built in: admin, editor, viewer. For a read-only accountant, create the user from Settings → Users → New user and set the role to viewer. The accountant will see every report, order and transaction, but every "save" or "delete" button is hidden and any direct API call returns HTTP 403.

Permission mapping is defined in config/permissions.php; you can add a fourth role by editing that file and running no migration (the role column is a free-form ENUM that accepts any string). A richer "per-user capabilities" screen is on the road map.

Email and SMS

Q8. Outgoing emails are not arriving. What should I check?

Walk through this decision tree:

  1. Open Admin → Settings → Mail and click Send test email to your own address. Does it arrive? If yes, your SMTP is fine and the issue is downstream (template filtering, recipient spam folder).
  2. If the test fails, check storage/logs/mail.log for the raw SMTP conversation. Look for 535 Authentication failed (wrong user or password), 550 Sender rejected (the SMTP_FROM address is not authorised on your provider), or connection timeouts (firewall blocking outbound port 587).
  3. Verify that your SPF, DKIM and DMARC records are aligned for the domain used in SMTP_FROM. Most modern providers silently discard unauthenticated mail.
  4. On shared hosting, outbound SMTP to third parties is often blocked. Use the host's own SMTP relay or a transactional provider over port 2525.

More background in the Configuration chapter, section Mail / SMTP.

Backups

Q9. How do I take a database backup, and where is it stored?

The admin UI has a one-click "Backup now" button at Settings → Backup. For automated daily backups, add the cron entry below. Backups land in storage/backups/ as gzipped SQL dumps, file-named pastane-YYYY-MM-DD-HHMM.sql.gz.

10 3 * * * cd /var/www/pastane && php bin/cron/db-backup.php

A companion monitoring job will warn you if the most recent backup is older than 25 hours, and will raise a critical alert at 48 hours. Backups older than the configured retention window (default 14 days) are automatically pruned.

Off-site copies. Backups on the same server are only half a backup. Synchronise storage/backups/ to an S3 bucket, Backblaze B2 or equivalent, and encrypt at rest. A scripted example is provided in bin/cron/db-backup.php.
Q10. How do I restore a backup?

Decompress and pipe into the MySQL client:

gunzip -c storage/backups/pastane-2026-04-20-0310.sql.gz \
  | mysql -u pastane_user -p pastane_db

For point-in-time recovery, use make db-restore FILE=path/to/backup.sql.gz; the Makefile target includes a five-second cancellation window to avoid fat-finger accidents on production.

Integrations

Q11. Is there WhatsApp integration?

Two flavours are shipped. Click-to-chat is free and zero-config: set your WhatsApp Business number under Settings → Contact and a floating button appears on every public page; tapping it opens the customer's WhatsApp with a pre-filled greeting. Outbound notifications via the WhatsApp Business API require a Meta-approved provider (Twilio, 360dialog, MessageBird). Enter the provider's credentials under Settings → SMS; the SMS driver family will be extended in a minor update to cover WhatsApp channels natively.

Q12. Can I integrate with a POS system or an accounting tool?

The public JSON API documented at /api/docs.php (staging only) exposes every order, customer and product. Use it to push sales into QuickBooks, Xero, Logo or Netsis. A webhook system is scheduled for the 1.1 release; in the meantime you can poll the orders endpoint every minute.

Performance

Q13. The dashboard feels slow during peak hours. What can I tune?

In order of impact:

  1. Switch CACHE_DRIVER from file to redis. Typical response-time improvement is 40-60%.
  2. Enable OPcache in your PHP configuration (opcache.enable=1, opcache.memory_consumption=192).
  3. Run php bin/cache-warm.php as a cron job every five minutes. This pre-populates the hot cache keys (featured products, active categories, daily revenue).
  4. Confirm the database has the indexes from migration 000005. The seed of EXPLAIN SELECT ... FROM siparisler should show type=range or better, not type=ALL.
Q14. What about horizontal scaling? Can I run more than one app server?

Yes. Move sessions to Redis (session.save_handler=redis), put storage/ on shared storage (NFS, EFS) or move logs to a central collector, and use a load balancer with sticky sessions. The blue-green deployment pattern documented under docs/BLUE_GREEN_DEPLOYMENT.md covers this end-to-end, including canary weighting.
