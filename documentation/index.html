Welcome

Thank you for purchasing the Tatli Dusler Pastane platform. This is a complete, production-ready web application for bakeries, patisseries, cafes and small restaurants. It combines a public-facing online menu, customer ordering, QR-code in-house ordering, and a full administrative back office in a single deployable package.

This documentation will walk you through everything you need to know, from the first minute after download to advanced operational tasks such as taking database backups and rotating secrets. Read the sections in order if you are a first-time installer, or jump to the FAQ if you are looking for a quick answer.

What is included

The package delivers a feature-rich, Turkish-developed but fully translatable bakery and cafe management system. Below is an at-a-glance summary of every major capability shipped in version 1.0.

Core Online Menu

Category-driven, responsive, mobile-first menu with cart, checkout, order tracking, and printable receipts. Search, filters, featured items and portion selection are all built-in.

Core QR Ordering

Each physical table has a unique QR code. Guests scan and place orders without downloading an app. Orders stream to the Kitchen and Waiter dashboards in near real time.

Admin Back Office

Full CRUD for products, categories, orders, tables, reservations and customers. Role-based access control (Admin, Editor, Viewer) with 23 granular permissions.

Security Hardening

CSRF protection, rate limiting, Content Security Policy with nonces, 2FA for administrators, backup codes, activity audit log, and session fingerprinting.

Ops Observability

Prometheus metrics endpoint, health-check probes for Kubernetes, optional Sentry error reporting, and rotated logs with configurable retention.

Ops Deployment

Dockerfile and docker-compose are provided for local, staging and blue-green production rollout. A single Makefile target covers setup, migrate, seed and smoke checks.

Technical highlights

Developers integrating or extending the platform will appreciate the following properties of the codebase:

  • Pure PHP 8.1+ backend, no heavyweight framework lock-in. A small but modern structure with Controllers, Services, Repositories and Validators.
  • MySQL 8.0+ schema with explicit migrations under database/migrations/. Idempotent seed script ships 5 categories, 15 demo products, 10 tables and one admin account.
  • Strict Content-Security-Policy with per-request nonces. No inline JavaScript handlers anywhere in the codebase (verified during the Sprint 4 audit).
  • OpenAPI 3.0.3 specification for the public JSON API, rendered via an optional Swagger UI gateway at /api/docs.php on non-production environments.
  • Prometheus metrics exported at /api/metrics.php and protected by a bearer token.
  • Health probes at /api/health with live and ready variants, suitable for Kubernetes or any load balancer.
